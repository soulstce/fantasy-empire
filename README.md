Fantasy Empire

A fantasy RTS + RPG prototype built with Next.js, TypeScript, and a canvas-based game engine.

Includes:
- Grid-based base building
- Villager roles and house population growth
- Top-down overworld with fog of war
- Cave screen for monster encounters
- Real-time combat queue with attack, defend, and spell actions
- D&D-style leveling, mana, spell learning, and health management
